# My Website - Trang Web Cá Nhân 

Dự án thực hành môn Lập trình Web. Trang web được xây dựng nhằm mục đích giới thiệu bản thân, trình bày lộ trình học tập, kỹ năng chuyên môn và cung cấp biểu mẫu liên hệ trực tuyến.

##  Cấu Trúc Thư Mục 
```text
my-website/
├── index.html        # Trang chủ: Thông tin cá nhân & mục tiêu
├── about.html        # Trang giới thiệu: Kỹ năng, lộ trình & kế hoạch môn học
├── contact.html      # Trang liên hệ: Biểu mẫu gửi thông tin với Validation
├── css/

├── images/           # Thư mục chứa hình ảnh minh họa & avatar
└── README.md         # File mô tả chi tiết dự án
